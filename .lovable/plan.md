
# Hairkunst Hair Salon Website

A bold, elegant hair salon website inspired by the reference design — dark/purple aesthetic with vibrant imagery, editorial typography, and smooth scrolling sections.

## Design Direction
- **Dark theme** with deep purples, blues, and gradients
- **Large, dramatic imagery** with vivid hair color photography (using high-quality Unsplash stock)
- **Editorial serif headings** (Playfair Display) + clean sans-serif body text (Inter)
- **Full-bleed sections** with asymmetric layouts mixing large images and text

## Sections (Single Page, Scroll-Based)

### 1. Hero
- Full-screen split layout: large vibrant hair photo on left, salon name + tagline on right
- "Scroll" indicator with animated arrow
- European & Asian styling artistry messaging

### 2. Welcome / About
- Large italic serif heading "Welcome. Guten Tag"
- Description of the salon's philosophy and approach
- Background image with gradient overlay

### 3. Services
- Grid/cards showing services: Cut & Style, Coloring, Treatments, Extensions, Bridal, etc.
- Each with icon, name, brief description, and starting price

### 4. Gallery
- Masonry-style photo grid showcasing hairstyle portfolio
- Hover effects revealing style details
- Using curated Unsplash hair/salon imagery

### 5. Outlets / Locations
- Cards for each salon location with address, hours, and a small map placeholder
- Phone numbers and directions links

### 6. Contact / Booking
- Clean section with salon info and an external booking link (prominent CTA button)
- Social media links

### 7. Footer
- Navigation links, copyright, social icons

## Navigation
- Fixed top navbar with logo + section links, transparent over hero, solid on scroll
